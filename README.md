# HLC Project

このプロジェクトは、ブロックチェーン技術を活用した NFT マーケットプレイスアプリケーションです。

## 注意事項

**このプロジェクトは別のリポジトリで管理されています。**

メインのプロジェクト管理や開発は、別のリポジトリで行われています。このリポジトリは特定の目的のために使用されています。

## プロジェクト概要

FastAPI ベースの Web アプリケーションで、以下の機能を提供します：

- ブロックチェーンによる取引管理
- NFT の作成・管理・取引
- ユーザー認証・認可
- マイニング機能
- チャット機能

## 技術スタック

- **バックエンド**: FastAPI, Python
- **データベース**: PostgreSQL (SQLAlchemy)
- **認証**: JWT, bcrypt
- **ブロックチェーン**: カスタム実装 (ECDSA 署名)

## セットアップ

### 必要な環境

- Python 3.x
- PostgreSQL

### インストール

```bash
pip install -r requirements.txt
```

### 環境変数

`.env`ファイルを作成し、必要な環境変数を設定してください。

### データベースの初期化

```bash
python recreate_db.py
```

### アプリケーションの起動

```bash
python main.py
```

または

```bash
uvicorn main:app --reload
```
